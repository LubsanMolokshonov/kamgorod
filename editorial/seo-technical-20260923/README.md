# Техническое SEO: первый этап, 23.09.2026

Изменения реализованы и развёрнуты на production 23.09.2026. Основной коммит `370e7b1`, исправление ссылки тегов блога по результату повторного обхода — `b748274`. Оба коммита опубликованы в `main`; контейнер `pedagogy_web` перезапущен. Новых миграций нет.

## Реализовано

- **FGOS-001/022:** единый builder ссылок курсов для каталога, AJAX, рекомендаций, главной и поиска; валидация slug, исправление реальных безслешевых ссылок. В HTML контента ссылки нормализуются через DOM, исходники не переписываются. Файлы/API/внешние адреса исключены. HTTP/www/слеш и затронутые legacy-пути нормализуются на конечный URL.
- **FGOS-003/004:** общая политика индексации каталогов и sitemap. Спорные непустые фасеты сохраняют canonical на родителя и исключаются из sitemap; пустые существующие — `200 noindex,follow` с self-canonical; неизвестные — `404`. Предстоящие вебинары автоматически открываются при наличии опубликованного будущего/текущего события. Ограничения трёх спорных курсовых страниц сохранены. Точные утверждённые редиректы олимпиад сохранены; автоматическое перенаправление любого пустого фасета вверх заменено согласованным состоянием пустого каталога.
- **FGOS-014:** серверная пагинация по 24 карточки, ограниченные SQL-выборки, стабильная сортировка с ID. SSR и GET `/ajax/catalog.php?path=/kursy/&page=2&q=…` используют общий запрос и рендер. Ответ: `success`, `html`, `total`, `pagination`, `page`; ошибочные запросы — 400, недоступная страница — 404, сбой — 500. Поиск работает по всей выборке, предыдущие запросы отменяются. Ссылки пагинации работают без JS; при сбое AJAX остаётся обычная ссылка. Полные массивы и дубли JSON удалены; новый JS и CSS вынесены в версионируемые файлы.
- **FGOS-015:** убран устаревший год из пяти хабов. Новые учебные периоды и даты проверки программ не выдуманы; исторические даты сохранены.
- **FGOS-018:** повтор названия в теле материала становится обычным блоком, остальные внутренние H1 — H2. H1 шаблона, текст БД и экспортные файлы сохранены.
- **FGOS-023:** единый источник видимых крошек и JSON-LD, текущий пункт без HTML-ссылки, с canonical в schema. Родительские фасеты не добавляются без подтверждения индексации; главная исключена. Удалено дублирование BreadcrumbList в блоге.
- Sitemap исключает уже перенаправленные публикации и неактивные аудитории. `mtime` файлов больше не выдаётся за дату содержательного изменения. Просмотры и скачивания не обновляют `updated_at` публикаций/материалов/вебинаров.

## Уточнения к ИИ-аудиту

FGOS-001 не воспроизведён среди настоящих ссылок ни на одной из 321 проверенной production-страницы. Строка `encodeURIComponent(slug)` внутри JavaScript сама по себе не является HTML-ссылкой. Общий builder и перенос рендера на сервер всё равно реализованы. Закодированные кавычки во внешних ссылках «Поделиться» не считаются дефектом URL.

До релиза на production 53 страницы материалов в обследованном наборе содержали два H1. После релиза обследованы 100 реальных production-материалов; повторных H1 нет. Локальный тест дополнительно проверил 100 временных HTTP-страниц.

Первый запуск выявил в локальной БД отсутствие уже существующей миграции 180 (`indexable_at`). Она применена только локально. Новых миграций эта реализация не требует; production-схема не менялась.
