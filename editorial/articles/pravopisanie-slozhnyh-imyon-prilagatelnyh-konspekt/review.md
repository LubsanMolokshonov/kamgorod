# Проверка комплекта

## Содержание

- Сохранены сильные элементы авторского замысла: урок-путешествие, географическая станция, лингвистическая сортировка, музейное задание, взаимопроверка и двигательная пауза.
- Удалены черновые пометки, незавершённые реплики и посторонний рекламный фрагмент, оборвавший исходную публикацию.
- Добавлены цель, наблюдаемые результаты, поминутный ход на 45 минут, ответы, балльные критерии, три уровня дифференциации, рефлексия и домашнее задание.
- Автору не приписаны проведение урока, апробация или результаты обучения.

## Языковая точность

- Формулировки сверены с § 50 ИПС ИРЯ РАН и словарём «Академос» 21.09.2026.
- Упрощённое правило «можно вставить союз и — ставь дефис» обозначено как ориентир, а не универсальная норма.
- Введена словарная стратегия для слов, которые не выводятся из четырёх учебных моделей.
- Все ответы в упражнениях отдельно проверены по академическим материалам.

## Изображение

- Обложка создана встроенным `image_gen`, сохранена только внутри закрытого комплекта.
- Русский текст проверен побуквенно; лишних надписей, логотипов и узнаваемого лица ребёнка нет.
- Публичный путь только зарезервирован в метаданных; общий каталог ассетов не изменён.

## Техническая проверка

- `article.md` содержит H1; `article.html` не содержит H1.
- HTML использует разрешённые элементы, не содержит скриптов, inline-обработчиков, `data:` URL или внешних изображений.
- Таблица получает внутренний горизонтальный скролл на мобильном экране через проектный CSS для публикаций.
- JSON-файлы валидны. `blogPostPackage()` проверил HTML и метаданные в изолированном временном корне с кандидатом обложки под зарезервированным публичным путём; ошибок нет.
