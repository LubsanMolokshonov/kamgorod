Конструктор рабочих программ предназначен для создания программ по обязательным учебным предметам. Шаблоны рабочих программ конструктора  соответствуют ФООП и ФРП. Обращаем внимание, что  конструктор предназначен для создания рабочих программ только в рамках обновленных ФГОС.
