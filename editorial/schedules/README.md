# Расписание редакционных статей

По запросу 14.10.2026 очередь переведена на ежедневный выпуск в 09:00 Europe/Moscow
(13:00 Asia/Ho_Chi_Minh). В `first-five-2026-10-14.json` первая, уже опубликованная,
статья сохраняет дату 14 октября; следующие четыре назначены на 15–18 октября.
`next-five-2026-10-14.json` содержит позиции 6–10 плана — 19–23 октября.
Времена имеют явный UTC offset. Часовой пояс сохранён из прежнего расписания.

Будущие статьи находятся только в закрытых файлах `editorial/articles/`. Запись в
`publications` создаётся при наступлении времени. Будущая дата у опубликованной
записи сама по себе не скрыла бы её на этом сайте, поэтому так не делаем.

Проверки:

```sh
php cron/process-blog-schedule.php --schedule=editorial/schedules/first-five-2026-10-14.json --validate-only
php cron/process-blog-schedule.php --schedule=editorial/schedules/first-five-2026-10-14.json
php cron/process-blog-schedule.php --schedule=editorial/schedules/first-five-2026-10-14.json --publish
```

Первая команда работает без БД; вторая — dry-run с preflight всей очереди.
Третья публикует только наступившие элементы. Локальный flock предотвращает
пересечение запусков расписания; публикационный GET_LOCK и транзакция защищают
каждую запись. Повтор сверяет slug, автора, источник, статус, текст, метаданные,
обложку и теги; совпадение пропускается, конфликт останавливает очередь. Дата всегда
содержит UTC offset. Подмена HTML, обложки или inline-иллюстрации блокирует выпуск.

`first-five-2026-10-14.cron` устанавливается отдельным файлом в host `/etc/cron.d/`,
сохраняется после пересоздания контейнера и не меняет другие cron-задания.
Следующая пятёрка подключается отдельным `next-five-2026-10-14.cron`:
host `/etc/cron.d/fgos-blog-next-five-20261014`.
Проверка каждые пять минут; при пропуске момента выполняется в следующий запуск.
После 31 октября 2026 эти одноразовые cron-записи не выполняются.

Текст статьи не меняется при работе со ссылками. `renderPublishedBlogLinks()`
разворачивает ссылки на ещё не опубликованные /blog/ в обычный текст на этапе
отображения. После выхода адресата они появляются автоматически.

Ограничение четвёртой статьи: сборка поделок проверена цифровой схемой, физическая
апробация не выполнялась. Это было сообщено пользователю перед его запросом
опубликовать все пять статей; не выдавать цифровую проверку за ручную сборку.
