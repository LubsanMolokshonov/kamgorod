# Библиотека редакционных источников

Библиотека хранит повторно используемые доказательства для редакционных статей.
Полные первичные документы находятся локально в `raw/` и не попадают в Git или на
production. В репозитории хранятся только карточки источников и короткие выдержки,
достаточные для проверки применённого утверждения.

## Правило работы

1. До новой статьи запустите `php scripts/editorial-source-library.php --list`.
2. Для нужного утверждения получите карточку: `--show=ID` или компактную выдержку:
   `--extract=ID --claim=CLAIM-ID`.
3. Если карточка применима и проверена для нужного учебного года, укажите в
   `sources.json` статьи `library_id` и `claim_id`; полный PDF повторно не скачивайте.
4. Если норма изменилась, вопрос новый или дата проверки устарела, скачайте новую
   версию в `raw/`, обновите карточку и выдержку. Не заменяйте доказательство
   предположением о том, что изменения отсутствуют.

Карточка не заменяет первичный источник. Она экономит контекст при подготовке статьи,
а URL, реквизиты, точный пункт, редакция и SHA256 позволяют повторно проверить вывод.
