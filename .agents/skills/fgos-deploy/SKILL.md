# Деплой fgos.pro

Деплой выполняется из репозитория в `/var/www/kamgorod` на `root@141.105.69.45`.
Веб-контейнер — `pedagogy_web`, база — `pedagogy_db`; production-репозиторий —
`git@github.com:LubsanMolokshonov/kamgorod.git`.

Перед началом прочитай [исходную команду Claude Code](../../../.claude/commands/deploy.md):
она является поддерживаемым источником процедуры. Не используй `docs/DEPLOYMENT.md`
как руководство для текущего production-деплоя: это устаревшая инструкция по ЮKassa.

## Порядок

1. Убедись, что пользователь явно запросил развёртывание. Проверь `git status` и
   `git log --oneline origin/main..HEAD`. Если рабочих изменений и непушенных коммитов
   нет, сообщи об этом и не выполняй действия на сервере.
2. До коммита собери CSS-бандл командой
   `docker exec pedagogy_web php scripts/build-assets.php`, если в целевом изменении
   есть `assets/css/fonts.css`, `main.css`, `search.css`, `redesign.css` или
   `redesign-info.css`. Добавь получившийся `assets/css/bundle.min.css` в тот же коммит.
3. Не добавляй `.env`, `vendor/` и личные файлы. Закоммить утверждённые изменения с
   понятным русским сообщением и выполни `git push origin main`.
4. На сервере проверь `git status`. Сохрани существующие серверные изменения отдельным
   именованным `git stash`, затем выполни `git pull origin main` и восстанови stash.
   При конфликте остановись и покажи пользователю состояние: не разрешай конфликт
   автоматически.
5. Если в целевом коммите есть миграции, выполни
   `docker exec pedagogy_web php /var/www/html/migrate.php`; при критической ошибке
   остановись. Для изменений без миграций зафиксируй, что миграции не требовались.
6. Перезапусти `pedagogy_web`; проверь, что контейнер имеет статус `Up`. Проверь HTTP
   200 у главной, `/kursy/` и у затронутой страницы; просмотри свежие логи контейнера.
   Для редакционной статьи дополнительно выполни проверки из навыка
   `pedagogical-articles`.

В отчёте укажи коммиты, миграции, перезапуск, HTTP-коды, проверенную целевую страницу
и незакрытые ошибки. Не выполняй публикацию статьи без согласования её готового
комплекта пользователем.
