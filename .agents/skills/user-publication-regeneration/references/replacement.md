# Безопасная замена существующей публикации

Этот этап выполняй только после явного разрешения изменить production и после чтения
`../../fgos-deploy/SKILL.md` по фактическому проектному пути.

## Скрипт обновления

Предпочитай проверяемый CLI-скрипт, а не ручной SQL. Он обязан:

1. запрещать веб-запуск guard'ом `CLI only`;
2. быть dry-run по умолчанию;
3. для записи требовать `--apply` и точный `--approved-sha256`;
4. начать транзакцию и выбрать ровно целевую строку по `id + slug FOR UPDATE`;
5. проверить ожидаемые `source`, `status` и SHA256 текущего `content`;
6. остановиться без ошибки записи, если согласованная версия уже установлена;
7. проверить хеш нового HTML и всего комплекта;
8. разрешить тип публикации по существующему slug типа, а не по догадке об ID;
9. до UPDATE сохранить JSON-снимок исходной строки в закрытом каталоге с правами 0600;
10. обновить только согласованные контентные поля и статусы готовых ассетов;
11. заполнить `content_original` через `COALESCE(content_original, old_content)`;
12. потребовать `rowCount() === 1`, затем commit; при исключении сделать rollback.

Не включай в общий репозиторий production-backup с пользовательскими данными. Не
перезаписывай строку, если исходный хеш изменился после подготовки: заново прочитай
версию, выясни причину и верни изменённый комплект на согласование.

## Последовательность

Локально проверь PHP syntax, редакционный комплект, хеши и dry-run на доступной БД.
Закоммить только файлы задачи. На сервере сначала выполни read-only проверки и dry-run,
затем один apply с согласованным хешем. Сетевой обрыв не разрешает слепой повтор:
сначала установи, изменилась ли публикация.

## Приёмка

На прежнем URL проверь HTTP 200, точные H1/текст, title/description, canonical,
robots, Open Graph, структурированные данные, обложку и все inline-изображения.
Проверь desktop и мобильную ширину. Убедись, что `id`, `slug`, `user_id` и связи с
документами не изменились, а закрытые `editorial/` и `.agents/` недоступны по HTTP.
Запиши backup, хеши, commit и результаты в `review.md`.
