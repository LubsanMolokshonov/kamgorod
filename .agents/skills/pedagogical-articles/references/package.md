# Комплект статьи

Каталог `editorial/articles/<slug>/` закрыт от веба целиком. Только чистовой HTML
записывается в БД, веб-обложка находится отдельно в `assets/images/blog/`.

- `brief.md`: задача, границы, аудитория, дата, критерии полезности.
- `research.md`: фактические запросы, прочитанные страницы, перечень практических
  вопросов и применимых требований со статусом (раскрыто / вне границ / блокер),
  метод исследования и ограничения SEO-данных.
- `sources.json`: для повторно используемой нормы — `library_id`, `claim_id` и цель
  использования; для уникального источника — URL, документ, редакция/статус,
  применимые пункты, дата проверки, сохранённый файл и его SHA256.
- `claims.md`: утверждение → тип → пункт и фрагмент → область применения (включая
  уровень, предмет, класс и условия, когда существенны) → результат.
- `sources/`: только уникальные для статьи документы и контекст. Общие первичные
  документы лежат один раз в `editorial/source-library/raw/` локально и исключены из
  Git; их карточки и выдержки — в `editorial/source-library/`.
- `article.md`: чистовой текст с H1 и публичными ссылками на источники.
- `article.html`: тот же текст без H1 (H1 выводит шаблон блога), без служебного отчёта.
- `metadata.json`: поля CLI `title`, `slug`, `content-file` (относительно manifest),
  `cover-image` (URL `/assets/images/blog/...`), `annotation`, `type`, `tags`
  (строка slug через запятую), `meta-title`, `meta-description`, `noindex` (boolean).
- `cover-original.png` и `cover-prompt.md`: оригинал, описание и alt.
- `review.md`: фактически выполненные проверки, включая полноту, актуальность на
  учебный год, сквозной пример, педагогическую логику и редактуру; блокеры,
  состояние согласования, хеш комплекта, затем URL/ID публикации и результаты
  проверки на сервере.

Не ставь approved/published и даты проверок авансом. Обновление текста/метаданных/
изображения меняет хеш и отменяет согласование прежнего комплекта.

Перед публикацией выполни `php scripts/editorial-check.php --article=<slug>`. Он
не заменяет содержательную проверку, но выводит короткий итог вместо повторного чтения
крупных файлов.
